# 한강버스 가이드 개인정보 처리방침

최종 업데이트: 2026-07-16

## 수집하는 정보
- 본 앱은 회원가입을 요구하지 않으며, 이름·연락처·위치 좌표를 수집하지 않습니다.
- 기기 언어·글씨 크기 설정은 기기 내(`SharedPreferences`)에만 저장됩니다.
- 선택적으로 크래시 리포트(Sentry)를 사용하는 빌드에서는 앱 오류 로그가 전송될 수 있습니다. DSN이 설정되지 않은 빌드에서는 전송되지 않습니다.

## 외부 서비스
- 서울시 OpenAPI (날씨·실시간 도시데이터)
- Open-Meteo (서울시 API 실패 시 폴백)
- 카카오맵 (지도 타일/JS SDK)
- 승선 신고는 외부 네이버 폼으로 이동합니다.

## 문의
앱 스토어 개발자 연락처 또는 프로젝트 저장소 이슈로 문의해 주세요.

이 문서는 스토어 리스팅용 초안입니다. 공개 URL은 `PRIVACY_POLICY_URL` dart-define 으로 지정합니다.
